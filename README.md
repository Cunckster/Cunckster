# Hi, I'm Cunckster 👋

I’m a curious, self-directed maker interested in understanding how things work and turning that understanding into practical tools.

My projects tend to sit at the intersection of **software, automation, local computing, digital preservation, and media processing**. I enjoy experimenting, adapting existing tools, and building small utilities when an existing workflow is unnecessarily complicated.

## Areas of interest

- 🐍 Python and practical automation
- 🪟 Windows tooling, scripting, and system customization
- 🤖 Local and privacy-focused AI
- 🎙️ Audio, speech recognition, transcription, and media processing
- 📄 OCR, PDF processing, and digital preservation
- 🐳 Docker and self-hosted applications
- 🍓 Raspberry Pi and small hardware/software projects
- 🔧 File management, metadata, conversion, and workflow automation

## Selected projects

### [CompressPDF](https://github.com/Cunckster/CompressPDF)
A browser-based PDF compression tool focused on privacy: files are processed locally rather than uploaded to a server. It is particularly useful for scanned-image PDFs.

### [Unattend Generator](https://github.com/Cunckster/unattend-generator)
A project for generating Windows `autounattend.xml` configurations, aimed at making automated Windows installation and configuration easier.

### [Audio Visualizer Python](https://github.com/Cunckster/audio-visualizer-python)
An experiment around generating visualizations from audio, combining signal processing with programmatic media creation.

### [Raspberry Pi Slideshow](https://github.com/Cunckster/rasp-pi-slideshow)
A small Raspberry Pi project for displaying images as a continuously running slideshow.

### [3D Land MSBT Editor](https://github.com/Cunckster/3DLandMSBTeditor)
A specialized tool exploring the editing of MSBT text resources used by Nintendo software.

### [LDTAGEditor V2](https://github.com/Cunckster/ldtageditor-v2)
A project focused on working with and editing media metadata and tags.

## Working with existing open-source software

Some repositories in my account are experiments, forks, adaptations, or local versions of larger open-source projects. They are part of how I learn, test ideas, and build a useful local toolkit.

Projects and technologies I have explored include **WhisperX, EasyOCR, AnythingLLM, OpenCut, Text Grab, Speedtest Tracker, and other open-source tools**.

## What I value in software

I generally prefer software that is:

- **Local-first** when practical
- **Open source** or transparent about how it works
- **Simple to operate** and easy to maintain
- **Useful in the real world**, rather than complex for its own sake
- **Reusable**, with automation and modularity where they provide a real benefit
